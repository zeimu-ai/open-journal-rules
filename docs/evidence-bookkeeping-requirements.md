# 証憑・帳簿要件（インボイス保存・交際費・電子帳簿保存法）

仕訳の正確性を担保するために必要な証憑・帳簿の要件をまとめる。各項目は国税庁の一次情報に基づく。本ドキュメントは仕訳ルール（`rules/*.json`）を補完する運用ガイドであり、実際の適用は事業者の状況・最新の法令改正を確認のうえ判断すること。

## 1. インボイス制度（適格請求書等保存方式）の保存要件 — issue #32

仕入税額控除を受けるには、原則として**適格請求書（インボイス）等と帳簿の両方の保存**が必要（消費税法30条⑦⑧⑨）。

### 1-1. 適格請求書の記載事項（6項目）

> 出典: 国税庁タックスアンサー [No.6625 適格請求書等の記載事項](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6625.htm)（2026-05-31 実装者確認）

1. 書類作成者の氏名または名称および**登録番号**
2. **取引年月日**
3. 取引内容（**軽減税率の対象品目である旨**）
4. 税率ごとに区分して合計した税込（または税抜）対価の額および**適用税率**
5. **税率ごとに区分した消費税額等**
6. 書類の交付を受ける事業者の氏名または名称

### 1-2. 帳簿の記載事項

課税仕入れの相手方の氏名・名称、取引年月日、取引内容（軽減対象の旨）、対価の額。

### 1-3. 免税事業者等からの課税仕入れの経過措置

`rules/invoice-transitional.json` 参照。80%控除（2023-10-01〜2026-09-30）/50%控除（2026-10-01〜2029-09-30）。
出典: [No.6498 適格請求書等保存方式（インボイス制度）](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6498.htm)、期間区分は平成28年改正法附則52条・53条。

## 2. 交際費等の飲食費に係る記載要件（1人1万円基準） — issue #33

法人の交際費等のうち、1人当たり**1万円以下**（令和6年4月1日以後。改正前は5,000円以下）の一定の飲食費は交際費等の範囲から除外できる（措置法61条の4、措令37条の5）。
出典: [No.5265 交際費等の範囲と損金不算入額の計算](https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5265.htm)（既存ルール rule-26/37/25 で引用・確認済）。

この除外の適用を受けるには、帳簿書類に次の事項の記載・保存が必要（**租税特別措置法施行規則21条の18の4**）。

1. 飲食等のあった**年月日**
2. 飲食等に参加した得意先・仕入先その他事業に関係のある者等の**氏名または名称およびその関係**
3. 飲食等に参加した**者の数**
4. その飲食等に要した**費用の額、飲食店等の名称および所在地**
5. その他飲食等に要した費用であることを明らかにするために必要な事項

> 注: 上記5項目の根拠は租税特別措置法施行規則21条の18の4。省令本文の逐語確認は本バッチでは未実施のため、適用時は最新の措規本文を確認すること。個人事業主には交際費の損金不算入規定の適用はない（事業関連性のある費用は必要経費、所得税法37条）。

## 3. 電子帳簿保存法（電子取引データ保存義務） — issue #44

電子取引（メール・EC・クラウド等で授受した請求書・領収書等の電子データ）は、**電子データのまま保存する義務**がある（電子帳簿保存法7条）。2024年（令和6年）1月から本格義務化され、原則として出力書面（紙）での保存に代えることはできない。

保存にあたっては「真実性の確保」（タイムスタンプ・訂正削除履歴等）と「可視性の確保」（検索機能・ディスプレイ等の備付け）の要件を満たす必要がある。

> 詳細・最新の運用は国税庁「電子帳簿保存法特設サイト」を参照。本項は電子帳簿保存法7条に基づく一般的記述であり、特定のタックスアンサー番号の引用は行っていない（該当ページを本バッチで確認できなかったため）。
