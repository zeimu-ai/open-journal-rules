# 保守カレンダー（税制改正・期限の追従）— issue #48

本データセットは特定時点の税制に基づく。**期限付き／改正予定のある項目**を一覧化し、メンテナンスの取りこぼしを防ぐ。各期日が到来したら、該当データを更新し本表を改訂すること。

> データ内の対応箇所: 期間限定ルールは `applicableYear` フィールド、経過措置率は `rules/invoice-transitional.json`、課税方式の前提は `rules/dataset-meta.json` を参照。

## 期限・改正カレンダー

| 期日 | 区分 | 内容 | 対応すべきデータ | 根拠 |
|------|------|------|----------------|------|

## 運用ルール

1. **鮮度テスト**（`tests/freshness.test.ts`）が citation の `verified_at` を6か月で警告・1年で失敗にする。警告が出たら一次情報を再確認し `verified_at` を更新する。
2. **URL生存テスト**（`tests/urls.test.ts`）が citation URL の 200 を確認する。リンク切れ（国税庁のURL改編等）が出たら最新URLに更新する。
3. 上表の期日が到来したら、該当データを更新し本表の該当行を改訂・追記する。
